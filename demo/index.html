What is this component library?

DCII Components is a collection of accessible, themeable web components built as custom elements with Shadow DOM. Each component follows WCAG 2.2 AA guidelines and can be styled via CSS custom properties.

How do I install it?

Include the library via a script tag or import the ES module. All components register themselves automatically — just use the HTML tags.

Can I customize the styling?

Yes. Every component exposes CSS custom properties (tokens) that you can override on :root or on the component element itself.

Is it accessible?

All components meet WCAG 2.2 AA requirements including keyboard navigation, ARIA attributes, focus management, screen reader announcements, and prefers-reduced-motion support.

Overview

DCII Components provides six production-ready web components. Each one is framework-agnostic, works with vanilla HTML, and requires no build step.

Installation

Add a single script tag to your page. All custom elements will register automatically and be ready to use in your markup. 

<script type="module" src="dcii-components/src/index.js"></script>

Theming

Override CSS custom properties on :root or on individual component instances. Every visual property — colors, spacing, radii, transitions — is controlled by a token.
